## 数据流

1. **采集**：用户在 Android 端拍照/选图/录像。
2. **上传**：App 请求预签名 URL，直传文件到对象存储。
3. **提交任务**：App 调用 `/jobs` 创建重建任务，后端扣减 credits 并入队。
4. **处理**：GPU Worker 消费任务，从存储拉取源文件，执行重建与增强。
5. **结果回写**：Worker 上传 GLB/纹理/预览图，调用后端 webhook 更新状态。
6. **预览/下载**：App 拉取结果，本地 Filament 预览或下载到设备分享。

## 质量分级

| 等级 | 输入 | 输出 | 预计耗时 | 适用场景 |
|------|------|------|----------|----------|
| Preview | 单图 | 低多边形 GLB，1K 纹理 | < 30 s | 快速预览 |
| Standard | 单图 / 多图 | 中等网格，2K PBR | 1–3 min | 通用产品 |
| High | 多图 / 视频 | 高密网格 + 细分，4K–8K 纹理 | 5–15 min | 影视/电商 |

## 技术选型总结

| 层 | 选型 |
|----|------|
| 移动端 | Kotlin + Jetpack Compose + CameraX + Filament |
| 后端 | FastAPI + PostgreSQL + Redis + RabbitMQ |
| Worker | Python + Docker + CUDA 12.4 |
| 图片→3D | TRELLIS.2（高保真）/ Stable Fast 3D（快速） |
| 视频→3D | COLMAP + gsplat + SuGaR |
| 纹理增强 | xatlas + Real-ESRGAN |
| 存储 | Cloudflare R2 + CDN |
| GPU 云 | Modal（主）+ RunPod Serverless（备） |
| 监控 | Prometheus + Grafana + Sentry |
